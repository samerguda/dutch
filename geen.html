الفرق المهم بين GEEN و NIET | GEEN | NIET | | :--- | :--- | | **Ik heb geen auto.**

هذا ليس صعبًا. | ### القاعدة السهلة: * **geen + اسم:** عندما تنفي وجود شيء أو امتلاك شيء أو تنفي اسمًا غير محدد. * **niet:** عندما تنفي صفة أو فعلًا أو مكانًا أو جزءًا آخر من الجملة. --- ## اختبر نفسك 1. **ليس لدي سيارة.** * [ ] Ik heb niet auto. * [x] **Ik heb geen auto.** * [ ] Ik ben geen auto. 2. **أنا لا أشرب القهوة.** * [x] **Ik drink geen koffie.** * [ ] Ik drink niet koffie. * [ ] Ik geen drink koffie. 3. **السيارة ليست غالية.** * [ ] De auto is geen duur. * [x] **De auto is niet duur.** * [ ] De auto niet is duur. 4. **لا توجد مشكلة.** * [x] **Geen probleem.** * [ ] Niet probleem. * [ ] Geen is probleem. 5. **ليس لدي وقت.** * [ ] Ik heb niet tijd. * [ ] Ik ben geen tijd. * [x] **Ik heb geen tijd.** --- 💡 **نصيحة للحفظ:** احفظ الجمل القصيرة أولًا: `Ik heb geen tijd` | `Ik heb geen geld` | `Geen probleem` | `Geen idee` | `Ik heb geen zin` هذه تعبيرات مفيدة جدًا في المحادثات اليومية في فلاندرز.
