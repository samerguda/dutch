الفرق المهم بين GEEN و NIET

GEEN NIET
Ik heb geen auto.
ليس لدي سيارة.		 De auto is niet duur.
السيارة ليست غالية.
Ik drink geen koffie.
لا أشرب القهوة عمومًا.		 Ik drink de koffie niet.
لا أشرب القهوة المحددة.
Er is geen probleem.
لا توجد مشكلة.		 Dat is niet moeilijk.
هذا ليس صعبًا.
القاعدة السهلة:
  • geen + اسم: عندما تنفي وجود شيء أو امتلاك شيء أو تنفي اسمًا غير محدد.
  • niet: عندما تنفي صفة أو فعلًا أو مكانًا أو جزءًا آخر من الجملة.

اختبر نفسك

1. ليس لدي سيارة.

  • a) Ik heb niet auto.
  • b) Ik heb geen auto.
  • c) Ik ben geen auto.

2. أنا لا أشرب القهوة.

  • a) Ik drink geen koffie.
  • b) Ik drink niet koffie.
  • c) Ik geen drink koffie.

3. السيارة ليست غالية.

  • a) De auto is geen duur.
  • b) De auto is niet duur.
  • c) De auto niet is duur.

4. لا توجد مشكلة.

  • a) Geen probleem.
  • b) Niet probleem.
  • c) Geen is probleem.

5. ليس لدي وقت.

  • a) Ik heb niet tijd.
  • b) Ik ben geen tijd.
  • c) Ik heb geen tijd.
