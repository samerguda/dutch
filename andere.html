📌 ملاحظة سريعة

  • ander = آخر مع اسم مفرد محايد — een ander huis
  • andere = أخرى أو آخر مع أسماء الجمع والأسماء من نوع de — andere mensen
  • een andere = شخص أو شيء آخر — een andere baan
  • iets anders = شيء آخر — Ik wil iets anders.
  • iemand anders = شخص آخر — Vraag iemand anders.
  • anders = بطريقة مختلفة / وإلا — Ik doe het anders.
  • verschillende = مختلفون / متنوعون / عدة — verschillende mogelijkheden
