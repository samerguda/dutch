1–25: الحياة اليومية (Het dagelijks leven)

  • Hoe gaat het? — كيف حالك؟
  • Hoe voel je je? — كيف تشعر؟
  • Hoe heet je? — ما اسمك؟
  • Hoe oud ben je? — كم عمرك؟
  • Hoe woon je? — كيف تعيش؟ / كيف ظروف سكنك؟
  • Hoe slaap je? — كيف تنام؟
  • Hoe laat sta je op? — الساعة كام تستيقظ؟
  • Hoe laat ga je slapen? — الساعة كام تذهب للنوم؟
  • Hoe begin je je dag? — كيف تبدأ يومك؟
  • Hoe breng je je dag door? — كيف تقضي يومك؟
  • Hoe maak je koffie? — كيف تحضّر القهوة؟
  • Hoe kook je rijst? — كيف تطبخ الأرز؟
  • Hoe maak je het huis schoon? — كيف تنظّف المنزل؟
  • Hoe was je je kleren? — كيف تغسل ملابسك؟
  • Hoe open je deze deur? — كيف تفتح هذا الباب؟
  • Hoe sluit je het raam? — كيف تغلق النافذة؟
  • Hoe gebruik je deze telefoon? — كيف تستخدم هذا الهاتف؟
  • Hoe werkt dit apparaat? — كيف يعمل هذا الجهاز؟
  • Hoe maak je dit klaar? — كيف تجهّز هذا؟
  • Hoe vind je deze film? — ما رأيك في هذا الفيلم؟
  • Hoe voel je je vandaag? — كيف تشعر اليوم؟
  • Hoe ziet je huis eruit? — كيف يبدو منزلك؟
  • Hoe ziet je kamer eruit? — كيف تبدو غرفتك؟
  • Hoe klinkt dat? — كيف يبدو صوته؟
  • Hoe ruikt het? — كيف رائحته؟

26–50: العمل والدراسة (Werk en studie)

  • Hoe werk je hier? — كيف تعمل هنا؟
  • Hoe zoek je werk? — كيف تبحث عن عمل؟
  • Hoe vind je een baan? — كيف تجد وظيفة؟
  • Hoe solliciteer je? — كيف تتقدّم لوظيفة؟
  • Hoe schrijf je een cv? — كيف تكتب سيرة ذاتية؟
  • Hoe bereid je je voor op een sollicitatiegesprek? — كيف تستعد لمقابلة عمل؟
  • Hoeveel ervaring heb je? — كم لديك من الخبرة؟
  • Hoeveel verdien je per maand? — كم تكسب شهريًا؟
  • Hoeveel uur werk je per dag? — كم ساعة تعمل يوميًا؟
  • Hoe laat begin je met werken? — الساعة كام تبدأ العمل؟
  • Hoe laat ben je klaar met werken? — الساعة كام تنتهي من العمل؟
  • Hoe doe je dit werk? — كيف تؤدي هذا العمل؟
  • Hoe los je dit probleem op? — كيف تحل هذه المشكلة؟
  • Hoe controleer je de machine? — كيف تفحص الآلة؟
  • Hoe repareer je dit toestel? — كيف تصلح هذا الجهاز؟
  • Hoe maak je een rapport? — كيف تُعدّ تقريرًا؟
  • Hoe schrijf je een e-mail? — كيف تكتب بريدًا إلكترونيًا؟
  • Hoe vraag je een baan aan? — كيف تتقدّم للحصول على وظيفة؟
  • Hoe leer je Nederlands? — كيف تتعلّم الهولندية؟
  • Hoe leer je nieuwe woorden? — كيف تتعلّم كلمات جديدة؟
  • Hoe spreek je dit woord uit? — كيف تنطق هذه الكلمة؟
  • Hoe schrijf je dit woord? — كيف تكتب هذه الكلمة؟
  • Hoe begrijp je deze zin? — كيف تفهم هذه الجملة؟
  • Hoe bereid je je voor op het examen? — كيف تستعد للامتحان؟
  • Hoe verbeter je je Nederlands? — كيف تحسّن لغتك الهولندية؟

51–75: المواصلات والسكن والحياة في بلجيكا (Transport, wonen en leven in België)

  • Hoe kom ik bij het station? — كيف أصل إلى المحطة؟
  • Hoe ga je naar je werk? — كيف تذهب إلى عملك؟
  • Hoe reis je naar Brussel? — كيف تسافر إلى بروكسل؟
  • Hoe ver is het station? — كم تبعد المحطة؟
  • Hoe lang duurt de reis? — كم تستغرق الرحلة؟
  • Hoe vaak rijdt deze bus? — كم مرة تسير هذه الحافلة؟
  • Hoe koop ik een treinkaartje? — كيف أشتري تذكرة قطار؟
  • Hoe moet ik overstappen? — كيف يجب أن أغيّر وسيلة النقل؟
  • Hoe kom ik thuis? — كيف أصل إلى المنزل؟
  • Hoe vind ik dit adres? — كيف أجد هذا العنوان؟
  • Hoe huur ik een appartement? — كيف أستأجر شقة؟
  • Hoeveel huur betaal je? — كم تدفع إيجارًا؟
  • Hoe betaal je de elektriciteitsrekening? — كيف تدفع فاتورة الكهرباء؟
  • Hoe werkt de verwarming? — كيف تعمل التدفئة؟
  • Hoe krijg ik warm water? — كيف أحصل على الماء الساخن؟
  • Hoe schrijf ik mij in bij de gemeente? — كيف أسجّل نفسي في البلدية؟
  • Hoe maak ik een afspraak bij de gemeente? — كيف أحجز موعدًا في البلدية؟
  • Hoe vraag ik een verblijfskaart aan? — كيف أطلب بطاقة إقامة؟
  • Hoe lang duurt de aanvraag? — كم تستغرق معالجة الطلب؟
  • Hoe ontvang ik mijn documenten? — كيف أتسلّم مستنداتي؟
  • Hoe open ik een bankrekening? — كيف أفتح حسابًا مصرفيًا؟
  • Hoe sluit ik een verzekering af? — كيف أبرم عقد تأمين؟
  • Hoe schrijf ik mij in bij VDAB? — كيف أسجّل نفسي في VDAB؟
  • Hoe vind ik een Nederlandse cursus? — كيف أجد دورة هولندية؟
  • Hoe kan ik hier integreren? — كيف يمكنني الاندماج هنا؟

76–100: أسئلة متنوّعة ومهمّة (Diverse en belangrijke vragen)

  • Hoeveel kost dit? — كم سعر هذا؟
  • Hoeveel kost dat per maand? — كم سعر ذلك شهريًا؟
  • Hoeveel geld heb je nodig? — كم تحتاج من المال؟
  • Hoeveel mensen komen er? — كم شخصًا سيأتي؟
  • Hoeveel tijd heb je? — كم من الوقت لديك؟
  • Hoe lang blijf je hier? — كم ستبقى هنا؟
  • Hoe lang woon je al in België? — منذ متى وأنت تعيش في بلجيكا؟
  • Hoe vaak sport je? — كم مرة تمارس الرياضة؟
  • Hoe vaak ga je naar de supermarkt? — كم مرة تذهب إلى السوبرماركت؟
  • Hoe laat begint de film? — الساعة كام يبدأ الفيلم؟
  • Hoe laat vertrekt de trein? — الساعة كام يغادر القطار؟
  • Hoe laat kom je thuis? — الساعة كام تصل إلى المنزل؟
  • Hoe snel kun je werken? — ما مدى السرعة التي يمكنك العمل بها؟
  • Hoe goed spreek je Nederlands? — ما مدى إتقانك للهولندية؟
  • Hoe moeilijk is deze oefening? — ما مدى صعوبة هذا التمرين؟
  • Hoe makkelijk is het om hier werk te vinden? — ما مدى سهولة إيجاد عمل هنا؟
  • Hoe belangrijk is dit voor jou? — ما مدى أهمية هذا بالنسبة لك؟
  • Hoe denk je daarover? — ما رأيك في ذلك؟
  • Hoe weet je that? (Hoe weet je dat?) — كيف تعرف ذلك؟
  • Hoe heb je dat gedaan? — كيف فعلت ذلك؟
  • Hoe ben je hier gekomen? — كيف وصلت إلى هنا؟
  • Hoe heb je dat geleerd? — كيف تعلّمت ذلك؟
  • How can I thank you? (Hoe kan ik je bedanken?) — كيف يمكنني أن أشكرك؟
  • Hoe kan ik je bereiken? — كيف يمكنني التواصل معك؟
  • Hoe kunnen we dit probleem oplossen? — كيف يمكننا حل هذه المشكلة؟
